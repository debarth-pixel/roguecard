Content Stage 05 Handoff: Shop Reroll Sink Plus Bounded Declutter

Completion Status
- Completed and verified on 2026-04-02.

Objective
- Add one new shop-only credit sink through a repeatable reroll service.
- Validate whether rerolls reduce excess end-of-run currency without destabilizing reward, shop, event, or save systems.
- Finish a bounded declutter pass using real screenshot review rather than a full UI redesign.

What Shipped
- Added `StateManager.reroll_shop_inventory()` as the shop-only reroll sink.
- Kept save compatibility at `v5` and extended active shop state through optional nested fields only:
  - `reroll_count`
  - `seen_card_ids`
- Rerolls now:
  - refresh only unsold card offers
  - preserve purchased/sold-out card slots
  - leave purge service unchanged
  - scale cost within a shop visit using `12 + (8 * rerolls_used_here)`
- Updated the headless economy audit to compare:
  - `baseline`
  - `current_tuned`
  - `reroll_enabled`
- Finished a bounded declutter pass across modal screens:
  - compacted top chrome
  - slimmed modal notice banners
  - removed most always-visible footer control strips
  - reduced reward purge CTA density
  - removed leftover placeholder card-art text from combat hand cards
  - removed redundant run-complete heading text
  - hid inactive event purge space

Audit Findings
- The reroll service works correctly and does increase paid sinks, but only slightly.
- On 200 seeds, reroll-enabled runs averaged:
  - `58.27` final credits
  - `0.51` shop card buys
  - `0.04` shop rerolls
  - `0.85` paid sinks
  - `11.55` final deck size
  - `0.94` win rate
- Compared with the already tuned Stage 04 baseline, rerolls only reduced final credits by `0.15` on average.
- Result: the reroll sink is stable and readable, but not strong enough by itself to fix the excess-currency problem.
